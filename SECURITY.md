# Security Policy

## Supported versions

`CCSWE.Avalonia.Hosting`'s major version tracks the supported Avalonia major (the
`12.x` line targets **Avalonia 12.x**). Security fixes are released against the
latest published version of the current major on NuGet.

| Version        | Supported          |
| -------------- | ------------------ |
| 12.x (latest)  | :white_check_mark: |
| < 12.0         | :x:                |

## Reporting a vulnerability

Please report security issues **privately** — do not open a public issue or PR.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab
and choose **Report a vulnerability**, or go directly to
<https://github.com/CCSWE-Avalonia/CCSWE.Avalonia.Hosting/security/advisories/new>.

Please include enough detail to reproduce — the affected version, a description of
the issue, and a proof of concept or steps if possible.

You can expect an acknowledgement within a few days. If the report is confirmed, a
fix will ship as a new NuGet release and a security advisory will be published with
credit to the reporter (unless you prefer to remain anonymous).
